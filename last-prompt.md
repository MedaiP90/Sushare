lets rework the session structure and workflow.

a session is composed by:
- one or more participants
- a personal order (with several dishes)
- a merged order (from all the participants)
- the checklist of the personal dishes to track what is arrived

a user can add to the personal order a series of dishes (automatically added to the restaurant menu too if not present). when all the users added their dishes the order can be "sent", this action prevent the order to be edited any more.

whan a order is sent, another order can be opened for the same session.

remember to strictly use the material design 3 on the session pages and widgets, this is mandatory
